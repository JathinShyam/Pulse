# Workspace Rules

When building the frontend for this application, you must leverage the **Stitch Skills** (which have been installed in `.agents/plugins/stitch-skills`).

## Frontend Strategy
1. **Design**: Use the `stitch-design` plugin to fetch or generate designs and UI components.
2. **Build**: Use the `stitch-build` plugin to scaffold React/Next.js components and link them to the Pulse API.
3. **Follow the Design Proposal**: Maintain the dark-mode SaaS dashboard aesthetic proposed in `frontend_design_proposal.md`.
